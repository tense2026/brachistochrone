# 最適강하선 탐색: 회전 상태 + 마그누스 효과 + Gymnasium 시각화

## 빠른 실행

Python 3.10 이상 권장. 압축 해제 후 이 폴더에서 실행합니다.

```bash
pip install -r requirements.txt
# 포함된 실제 150세대 결과를 바로 배속 재생 (재학습 없음)
python brachistochrone.py --replay-only --output-dir magnus_example
# 기본 1500세대 새 학습: 실시간 경로 표시 → 재생창
python brachistochrone.py
# 작은 시험 학습
python brachistochrone.py --episodes 150 --pop-size 16 --output-dir results
# 화면 없이 저장
python brachistochrone.py --episodes 150 --no-show
```

GUI 창은 일반 데스크톱 Python의 GUI 지원 Matplotlib 환경에서 사용하세요. Gymnasium의 human/rgb_array 렌더링을 Matplotlib로 구현했습니다. 배속은 재생 속도이지 학습 연산 가속이 아닙니다.

## 이번 변경

- 이동평균, 스플라인, 거칠기 벌점 없이 원시 행동에서 경로 생성.
- 기존 진화전략 탐색과 최단 기록 갱신 수정 유지.
- **마그누스 힘과 수직항력의 결합 추가.**
- **각속도 omega를 시간에 따라 적분.** 미끄러짐 마찰은 접촉점 상대속도의 반대 방향으로 작용하며 회전 토크에도 반영됩니다. 굴림에 필요한 정지마찰을 감당할 수 있으면 순수 굴림, 불가능하면 미끄러짐으로 계산합니다. 미끄러짐이 0이 되는 시점에서 시간 단계를 분할합니다.
- **트랙 접촉 이탈은 실패로 처리.** 공중 비행/재착지는 구현하지 않았습니다.
- 직선·고전 사이클로이드·학습 곡선을 동일 조건으로 비교. 별도 행 `rotation_lift_off_same_path`는 동일 경로에서 마그누스 힘만 끈 값입니다. 끈 조건에서 다시 최적화한 값은 아닙니다.
- 기본 실행은 새 동적 회전 모델입니다. Python API에서 옵션 없이 직접 생성한 환경은 기존 테스트/외부 코드 호환을 위해 이전 모델을 유지합니다. 새 환경은 `BrachistochroneEnv(dynamic_spin=True, use_magnus=True)`로 생성하세요. 마그누스 사용 시 동적 회전도 자동 활성화됩니다.

## 힘과 회전 부호

정지한 공기, 오른쪽 전진, 회전축은 운동 평면에 수직인 2차원 모델입니다.

- 접선 t: 진행 방향. 법선 n: 트랙에서 공 쪽(대체로 위쪽).
- omega > 0: 반시계 회전, 오른쪽 이동 기준 백스핀.
- omega < 0: 시계 회전, 오른쪽 이동 기준 톱스핀/보통의 전진 굴림.
- 접촉점 미끄러짐 속도 u = v + R*omega. 순수 굴림은 omega = -v/R입니다.
- S = R*omega/v
- C_L = clip(lift_slope*S, -lift_cap, lift_cap)
- F_M,n = 0.5*rho_air*pi*R^2*v^2*C_L
- N = m*(g*cos(theta) + v^2*kappa_center) - F_M,n
- 각가속도 = R*f / I, I = k*m*R^2

**lift_slope=0.5, lift_cap=0.5는 예시 현상론 계수이지 측정된 구의 상수가 아닙니다.** 회전 매개변수와 레이놀즈수, 표면 상태에 따른 실제 C_L을 측정/검증해야 합니다. v=0이면 힘을 0으로 계산합니다. 공기저항 on/off는 항력만 제어하며, 마그누스는 별도 옵션으로 제어합니다. 진공 조건은 공기 밀도를 0으로 놓거나 두 효과를 모두 꺼야 합니다.

마그누스 힘은 이 모델에서 접선에 수직이므로 직접 하는 일은 0입니다. 수직항력, 마찰, 접촉 유지 조건을 통해 운동에 영향을 줍니다. 마찰 여유가 충분한 순수 굴림에서 항력과 경로가 같으면 마그누스 힘만으로 접선 가속도가 달라지지 않습니다.

## 백스핀/톱스핀과 힘 끄기 실험

```bash
# 초기 백스핀 +100 rad/s (마찰에 따라 이후 변화)
python brachistochrone.py --omega0 100 --output-dir backspin
# 초기 톱스핀 -100 rad/s
python brachistochrone.py --omega0 -100 --output-dir topspin
# 힘만 끄고 동일한 동적 회전/마찰 모델로 재학습
python brachistochrone.py --no-magnus --output-dir without_magnus
# 저장 경로 고정 상태로 초기 회전/힘 유무 민감도 및 시간 간격 검사
python compare_magnus.py --output-dir magnus_example
```

초기 spin을 고정 유지하는 외부 모터는 없습니다. `--omega0`는 초기값일 뿐이며 이후 마찰 토크로 변합니다. 초기 각속도가 다른 실험은 초기 회전 에너지도 다르므로 공정한 동등 에너지 비교가 아닙니다. 회전 미고려 패널은 각속도 0인 구속된 미끄러짐 기준이므로 마그누스 힘도 0입니다.

기본은 v0=0, omega0=0입니다. 전진하면서 시계 방향으로 회전하게 됩니다. 백스핀은 처음부터 주지 않는 한 자동으로 지속되지 않습니다. 구름저항은 별도로 추가하지 않았습니다. 정지마찰이 그 자체로 에너지를 소모하는 것은 아닙니다.

## 재생 화면

- `Speed`: 0.25~20배속.
- `Generation`: 실제 저장된 세대의 최선 경로로 이동. 경로 사이의 평활화 없음.
- `Pause / Play`: 일시정지/재생.
- `Race / Evolution`: 선택 세대 경로의 물체 낙하 / 경로 개선 과정. 1배속 Evolution은 초당 10세대, Race는 실제 물리 초 기준입니다.
- `Restart`: 현재 모드 재시작.
- `no_rotation / rotation`: 회전 조건 전환.
- 현재 학습 경로 위 물체의 각속도, 마그누스 힘, 수직항력을 표시합니다. 힘의 부호는 위 법선 기준입니다.
- 물체 마커는 트랙 위 좌표이며 실제 구의 정확한 질량중심 오프셋은 아닙니다.

## 실제 실행 결과와 해석

`magnus_example/`은 seed=42, 150세대, 모집단 16, 30구간, dt=0.005초, 초기 회전 0으로 직접 실행한 결과입니다. 완전 수렴 또는 전역 최적 증명이 아닙니다.

| 회전 조건 | 직선 | 고전 사이클로이드 | 학습 곡선 |
|---|---:|---:|---:|
| 회전 미고려 | 0.913542 s | 0.678186 s | 0.676459 s |
| 동적 회전 + 마그누스 | 0.837099 s | 0.654274 s | 0.653024 s |

같은 학습 곡선에서 힘만 끄면 0.653004 s입니다. 이 설정에서 마그누스 영향은 약 0.0000192 s(약 19마이크로초)로 작습니다. **효과를 크게 보이게 하려고 공기 밀도나 계수를 임의로 부풀리지 않았습니다.** 시간 간격을 줄였을 때의 절대 시간 변화가 이 차이보다 클 수 있으므로, 이 작은 시간 차이를 실험적으로 확정된 효과나 경로 변화의 증거로 해석하지 마세요. `timestep_check.csv`와 `magnus_sensitivity.csv`를 확인하고 시간·공간 격자 수렴과 여러 시드 재학습을 수행해야 합니다.

총 16개 테스트 통과: 기존 11개 + 힘 부호/0 조건, 순수 굴림 에너지 보존과 시간 간격, 미끄러짐 반대 방향 마찰, 순수 굴림에서 직접 가속 없음, 접촉 이탈 실패 처리. 새 환경의 Gymnasium check_env도 통과했습니다. 실제 데스크톱에서의 마우스 조작은 검증하지 않았습니다.

## 사용자가 정리한 설명에서 주의할 점

1. 저항이 커질수록 항상 직선으로 수렴하거나 최저점이 반드시 올라간다고 일반화할 수 없습니다. 저항 법칙, 경계점, 경로 제약에 따라 최적해가 달라집니다. 원래 사이클로이드도 임의 두 경계점 사이 구간은 좌우 대칭일 필요가 없습니다.
2. 마찰/항력 없는, 반지름을 무시한 일정 관성계수의 순수 굴림은 시간에 sqrt(1+k)만 곱해져 모양을 유지합니다. 유한 반지름, 접촉 제약, 마찰 한계가 있으면 같은 결론을 그대로 적용할 수 없습니다.
3. 톱스핀 하향력은 레일 위에서 직접 접선 가속을 늘리는 힘이 아닙니다. 주로 수직항력과 마찰을 바꾸므로 항상 더 가파른 경로를 만든다고 말할 수 없습니다.
4. 이탈 조건은 단순히 '양력 > 중력 수직성분'만이 아니라 곡률과 속도에 따른 법선 가속까지 포함한 N<0입니다.
5. 마그누스 항은 간단한 압력차 설명만으로 실제 크기를 정할 수 없습니다. 여기서는 통상적인 양력 계수 모델을 쓰되, 계수의 실험 검증은 남겨두었습니다.

## 남아 있는 근사와 연구 한계

- 각진 구간별 직선 트랙에 유한차분 곡률을 사용하므로 기하학적으로 엄밀하지 않습니다. 반지름 보정은 법선 가속에만 적용하고 질량중심 궤적 전체를 오프셋하지 않습니다. 각진 경로를 이용하는 수치적 편법 가능성이 남습니다.
- 매 시간 단계에서 힘을 고정하는 근사 적분입니다. 곡률, 시간 간격, 구간 수 수렴 검사가 필요합니다. `--physics-dt 0.0025`, `--segments 60` 등을 사용하세요.
- 정지/운동 마찰계수는 같은 mu이며 구름저항, 공력 회전 감쇠, 바람, 3차원 운동, 공중 비행/재착지는 생략했습니다. 이탈 실패는 접촉을 유지하는 트랙만 찾는 제약입니다.
- 초기 각속도는 외부에서 주어질 수 있지만 외부 구동을 계속 넣지는 않습니다.
- 학습기는 신경망 PPO/SAC가 아닌 엘리트 보존 진화전략입니다. 고정 조건의 경로 최적화이지 다양한 조건에 일반화하는 순차 정책 학습이 아닙니다.
- 이전 최단 기록 정체는 좋은 후보의 기록 누락, 나빠진 평균 정책 수용, 보상과 최단 시간의 목적 불일치 등으로도 생겼습니다. 정체만으로 학습이 무의미하거나 이미 최적이라고 판단할 수 없습니다.
- 이전 물리 모델의 숫자를 새 모델과 직접 비교해 마그누스의 효과라고 해석하지 마세요. 힘 유무만 비교하려면 새 모델 내에서 on/off 해야 합니다.
